# AM25S016 Preconditioner Toolkit

A C++ implementation of a 2D Poisson Equation Solver with multiple iterative and direct methods.

## Features

- Direct Solver
- LU Factorization
- Cholesky Factorization
- Jacobi
- Gauss-Seidel
- Symmetric Gauss-Seidel (SGS)
- Successive Over Relaxation (SOR)
- IC(0)
- ILU(0)

## Preconditioners

- None
- Left
- Right
- Split

## Dependencies

- Eigen 3.4+
- C++17

## Build

make

## Run

./poisson_solver
